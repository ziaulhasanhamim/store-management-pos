# v0.8.31 — Mobile-friendly report tables, unified summary strips & non-wrapping totals

Global design system overhaul across all report pages to deliver an optimized mobile experience:
- **Unified Summary Cards**: Replaced multiple separate stacked vertical metric cards with a single compact, responsive summary strip card (`grid-cols-2 gap-3 sm:gap-4 md:grid-cols-3 lg:grid-cols-5`) across all 12 report modules.
- **Container Overflow Protection**: Strengthened `.panel` (`w-full min-w-0 max-w-full overflow-hidden`) and `.table-scroll` (`w-full min-w-0 max-w-full overflow-x-auto`) so large tables never stretch or overflow page boundaries on mobile devices.
- **Non-Wrapping Column-Aligned Totals**: Eliminated distorted wrapping flex summary blocks below tables and moved totals into native `<tfoot>` table footers with `whitespace-nowrap font-mono text-right` aligned under corresponding columns.
- **Clean Mobile Viewports**: Hid the secondary top scrollbar (`.table-top-scroll`) on mobile screens (`< 640px`) where touch swiping is native.

Validation: Solutions build with 0 warnings and 0 errors; all unit tests and integration tests pass cleanly across both repositories.
